Frequently Asked Questions

How long does it take to onboard a new Odoo client with Sadeem?

Under 5 minutes. When a subscription invoice is confirmed, Sadeem automatically creates the DNS record via Cloudflare, generates the SSL certificate, deploys the Docker container via Portainer, installs the module package, and configures S3 backups — all without manual intervention.

How do I get the module?

Contact us at support@sadeem.cloud to get access. Full documentation and setup guides are available at saas.docs.sadeem.cloud.

Is Sadeem similar to Odoo.sh?

Sadeem is self-hosted and gives you full control over your infrastructure, similar to Odoo.sh in automation but without the monthly per-instance fees. Unlike Odoo.sh, Sadeem supports both Docker and DBFilter modes, works on any cloud provider, and covers Odoo versions 14–19. Odoo.sh is designed for developers building on Odoo; Sadeem is designed for Odoo Partners who host and manage client subscriptions. There are no per-instance fees and no limits on subscriptions or servers.

How many clients can I manage with Sadeem?

Unlimited. Era Group in Saudi Arabia and Raqmia Technologies in Qatar both run their entire Odoo hosting portfolio on Sadeem with 80+ active subscriptions.

What's the difference between Docker and DBFilter deployment?

Docker: Each subscription runs in its own isolated container with dedicated resources. Best for customers who need custom modules, Git integration, Code Server, and full isolation.
DBFilter: Multiple subscriptions share a single Odoo instance, filtered by database. Lighter on resources, easier to manage, ideal for simpler use cases.

Which Odoo versions are supported?

The master module runs on Odoo 18, but you can manage subscriptions running on Odoo 14, 15, 16, 17, and 18+. Multi-version support is built-in.

Is there a demo available?

Yes. The Sadeem team conducts live demo meetings on request. Email support@sadeem.cloud to schedule one. There is no public self-service sandbox.

What about technical support?

Technical support is paid. Common channels:

Documentation: saas.docs.sadeem.cloud — comprehensive user guide and developer reference
GitHub Issues: for bug reports and feature requests, reviewed when time permits with no SLA
Paid support hours: for installation help, configuration assistance, and troubleshooting — billable hourly. Contact support@sadeem.cloud for current rates.

Do you offer custom development?

Yes. The Sadeem team offers paid custom development for features specific to your business. Email support@sadeem.cloud with your requirements for a quote.

How do I get updates?

Updates are delivered through your licensed access to the repository. The changelog documents every release. Always test updates in a staging environment before applying to production.

Will my customizations work after updates?

That depends on the changes. We follow semantic versioning — minor and patch releases preserve backward compatibility, major releases may include breaking changes. Always test updates in a staging environment before applying to production. The changelog documents every breaking change.

Can the Sadeem team host the platform for me?

Yes. Managed hosting is available as a paid service — we operate the Master Odoo, customer instances, and backup infrastructure on your behalf. Contact support@sadeem.cloud for pricing and SLA options.
